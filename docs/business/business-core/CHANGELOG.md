# 业务核心公共契约变更记录

## 2026-11-15 - v1.3.0

### 基线

- 正式业务基线切换到 `develop@63c2a14`。
- PR #12 已把认证、RBAC 和高并发保护合并到 `develop`。
- 业务分支不再依赖旧的 `feature/rbac-auth` 提交。

### 新增与修改

- 冻结个人档案第一阶段字段。
- 当前用户响应补充 `student_no`、`title` 和档案 `version`。
- 档案修改移除技能标签、研究方向和个人指导上限字段。
- 届次增加固定/范围人数模式及届次教师指导上限。
- 届次详情补充评审和公示时间、报名窗口、作品窗口和只读状态。
- 冻结届次状态数据库映射、手动推进、发布校验、修改限制和归档只读规则。
- OpenAPI 升级到 `1.3.0`，接口汇总同步，`1.2.1` 已归档。
- 增加数据库增量、回滚、权限种子和开发测试数据脚本。

### 当前范围

- 只开放个人档案和竞赛届次两个业务项。
- 不生成正式任务卡，不实现 Controller、Service、Mapper 或前端页面。
