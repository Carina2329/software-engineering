- 路径前缀：下表路径均相对于 `/api/v1`

## 公共错误码变更

- `50003`：认证或幂等依赖暂不可用；HTTP 503；可重试。
- `50001` 仍专指 AI 服务暂不可用。
- `50002` 仍专指对象存储暂不可用。
- `20001`、`40002` 及其他既有错误码的含义保持不变。
